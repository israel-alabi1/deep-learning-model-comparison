# Data

Raw datasets are not committed to this repository.

## Jena Climate

Place the Jena Climate CSV at:

```text
data/jena_climate_2009_2016.csv
```

## Local Chairs vs Shoes

Place the local dataset at:

```text
data/local_chairs_shoes/
├── Train/
│   ├── Chairs/
│   └── Shoes/
└── Test/
    ├── Chairs/
    └── Shoes/
```

The supplied local dataset contains 36 training images and 8 test images.

## MNIST and CIFAR-10

These datasets are downloaded automatically by Keras when the CNN notebook is run.
